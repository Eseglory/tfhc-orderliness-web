# Absence requests

Members open **Request absence approval** on an event, or visit `/member/submit-excuse`. Select the event, a reason category, and an explanation. The request remains pending until leadership reviews it. **My absence requests** shows the saved request, decision, and review note; use Refresh requests to retrieve updates.

Admins open **Review absence requests** on their dashboard (`/admin/absence-requests`). Each pending request shows the member, event, date, and explanation. Add an optional note and choose Approve or Reject. A reviewed request cannot be reviewed again.

Approval records EXCUSED attendance with zero points and an attendance audit entry. Rejection leaves attendance unchanged. An event RSVP of “Not attending” does not constitute an approved absence; members must submit an absence request separately.

Members can read only their own request history and cannot review requests. Decisions create an in-app Activity notification and remain visible in the request history. No email is sent by this flow.
